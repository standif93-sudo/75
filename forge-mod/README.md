# Forge Egg Mod 1.20.1

Мод для Minecraft Forge 1.20.1, который добавляет яйцо призыва кузницы.

## Описание

Этот мод добавляет:
- **Яйцо призыва кузницы** - специальный предмет для призыва сущности "Кузница"
- **Сущность "Кузница"** - при взаимодействии создает небольшую структуру кузницы с наковальней и сундуком
- **Сундук с лутом** - содержит 64 алмаза и 64 хлеба

## Требования

- Minecraft 1.20.1
- Forge 47.3.0 или выше
- Java 17

## Установка

### Способ 1: Сборка из исходников

1. Убедитесь, что у вас установлена Java 17
2. Откройте терминал в папке с проектом
3. Выполните команду для сборки:
   ```bash
   ./gradlew build
   ```
   (на Windows: `gradlew.bat build`)
4. Готовый .jar файл будет находиться в папке `build/libs/`
5. Скопируйте файл `.jar` в папку `mods` вашего Minecraft

### Способ 2: Использование готового файла

Если у вас уже есть скомпилированный файл мода:
1. Скопируйте `.jar` файл в папку `mods` вашего Minecraft
2. Запустите игру с профилем Forge 1.20.1

## Использование

1. Запустите Minecraft с установленным модом
2. Получите яйцо призыва кузницы через креативный режим (вкладка "Яйца призыва")
3. Используйте яйцо на земле в любом биоме (в том числе plains)
4. Появится сущность "Кузница"
5. Кликните правой кнопкой мыши по сущности
6. Сущность создаст структуру кузницы и исчезнет
7. В сундуке вы найдете 64 алмаза и 64 хлеба
